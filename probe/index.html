THEOL 书签兼容性测试

此测试用于确认“单元学习”页面能否运行轻量版书签程序。

隐私边界：测试至多读取一份页面中已经存在的规范预览元数据页面（最多 64 KiB），不会请求下载地址或课件正文，也不会上传、收集、存储或复制任何内容。
  1. 按 Ctrl+Shift+B 显示书签栏，把下面的“自包含测试”拖到书签栏。
  2. 打开已登录的 THEOL“单元学习”，展开一个明显含有课件的单元。
  3. 运行书签，点击浮层中的“捕获下一次单元点击”。
  4. 只点击一次另一个可见单元；测试会拦截这次点击，页面不会跳转。
  5. 只发送测试浮层的截图。

远程加载测试

若远程加载失败：请删除刚才的测试书签，再把下面的自包含测试拖到书签栏运行。它不加载 GitHub 脚本。
