# 课程资源助手

北京化工大学 THEOL 教学平台（course.buct.edu.cn）的本地课件下载工具，非学校官方产品。当前发布版为 **2.6.1**，包含书签版和 Chrome 扩展。

## 构建与测试

需要 Node.js 22+。官网、书签和扩展安装包现在由同一 Node 构建生成，不需要 Python；旧的 Python 打包入口仍兼容。请在**仓库根目录**运行：

```bash
npm ci
npm test
npm run build
```

构建结果：

- `dist/extension/`：可加载的 Chrome 扩展。
- `dist/buct-course-downloader.zip`：当前扩展的离线安装包。
- `dist/site/`：官网、自包含书签、同版本安装包和 `release.json` 校验信息。

**不要直接加载源码目录 `extension/`**。共享模块需要先打包；源码目录不再是独立的扩展安装包。

## 官网与发布

官网为 [h.yourba.top/THEOL-downloader](https://h.yourba.top/THEOL-downloader/)，由独立站点仓库 [vg188/h5-release](https://github.com/vg188/h5-release) 的 `THEOL-downloader/` 目录发布；[GitHub Pages](https://vg188.github.io/THEOL-downloader/) 保留为镜像。页面版本、书签代码、Chrome 扩展 manifest 与安装包来自同一 `RELEASE_VERSION`；`release.json` 提供包体大小和 SHA-256。新版发布前，线上可能仍显示旧版本，应以线上 `release.json` 与部署记录为准。

发布时必须同步两个仓库，不能只推送工具源码：

1. 本仓库的 `codex/bookmarklet-probe` 分支触发 GitHub Pages 工作流：安装锁定依赖 → 完整单元回归 → 当前版构建（含安装包）→ 发布 `dist/site/`。
2. 将同次构建的 `dist/site/` 同步至 `vg188/h5-release` 的 `THEOL-downloader/`，包含 `assets/`、`downloads/`、书签和 `release.json`。只提交这个产品目录，保留仓库根目录和其他产品；推送 `main` 后由已配置的 Cloudflare Pages 发布。
3. 两处部署均成功后，核对官网与镜像的页面、`release.json` 和安装包 SHA-256。官网重设计和发布检查见 [官网验收记录](docs/website-redesign.md)。

## Chrome 扩展

1. 运行 `npm run build:extension`。
2. 打开 Chrome 的扩展管理页，开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择 `dist/extension/`，登录教学平台并进入课程页。
4. 点击扩展图标，在标签页面板中扫描、勾选、下载。

首次汇总整门课程的资源目录树和发现的全部学习单元；「全部课程／课程资源／单元学习」只切换本地视图，不重新请求页面、不清空选择。同课内切目录、切单元或重新打开面板不会让列表失效；需要更新内容时主动点击「刷新列表」。下载队列最多同时运行 2 项，关闭面板不影响已提交任务。后台恢复时无法确认的任务会要求手动核对，避免重复下载。单项状态查询临时失败不取消其他下载；队列活动期间使用 Chrome alarms 低频对账，关闭面板后也可恢复，队列结束后移除唤醒。

如果之前加载的是源码目录 `extension/`，请先停用旧扩展，再加载 `dist/extension/`。之后每次重新构建，在扩展管理页点「重新加载」，并**刷新课程页**。

`npm run build` 会同时生成 `dist/buct-course-downloader.zip` 与官网里的 `downloads/buct-course-downloader.zip`，两份字节一致。也可以单独运行 `npm run package`；不需要把用户导向源码压缩包。

## 书签版

运行 `npm run build:site`。可通过本地静态服务预览：

```bash
python -m http.server 4173 --bind 127.0.0.1 --directory dist/site
```

打开 [本地安装页](http://127.0.0.1:4173)，把「课程资源助手」拖到书签栏。在已登录的课程页点击书签：

- 一次汇总课程资源目录树和发现的全部学习单元，不再重复确认读取范围；扫描不会自动下载文件。
- 通过搜索、类型筛选和树状复选框选择文件，不自动勾选。
- 没有原文件下载按钮的资源也会解析预览内容。可保存的预览副本可以勾选、打包或逐个下载；不支持的项目保留具体原因和平台预览链接。
- 默认优先生成 ZIP，可保留目录或平铺。默认上限为 200 MB、120 个文件。
- 超限改为逐个下载前会再次确认。逐个下载不能保留目录结构。
- 「关闭／隐藏」保留当前任务；再次点击书签会打开同一面板。「停止」取消后续读取。同课内的页面操作不要求重新汇总，真正换课后才拒绝旧列表。

书签任务依赖当前页面，生成 ZIP 时不要刷新或离开课程页。界面中的「已触发」不等于文件已保存，请核对浏览器下载列表。更新后需要从安装页重新拖入书签。

## 预览资源也能下载

按以下顺序选择可保存内容：

1. **原文件／整份原格式资源流**：优先使用匹配的原文件入口；没有下载按钮时，继续解析预览页声明的同资源文件流。完整校验通过后保留原名和字节，不因接口叫 PDF 就改成 `.pdf`。
2. **平台整份 PDF**：找到平台提供的完整预览 PDF 时，直接保存响应，不重新请求分页图片或合成文件。
3. **图片预览 PDF**：没有找到整份 PDF、只有分页图片清单时，逐页校验并按顺序合成 PDF；任何一页失败，都不会生成缺页 PDF。
4. **其他预览**：播放器中的独立媒体文件按实际格式保存；Word 富文本预览保存为带内嵌图片的离线 HTML；纯在线文本保存为 UTF-8 TXT。

预览入口下载的文件不额外添加「（预览版）」等命名标记。原格式保留原名；平台转换或本地导出时只按实际格式调整扩展名，必要的来源说明留在界面或文件元数据中。PDF/HTML 不会伪装成 PPTX/DOCX；图片合成的 PDF 不含原课件的可编辑内容、动画、备注和平台未提供的页面。分段流、外站媒体和无法可靠解析的预览仍显示原因，不猜测下载地址。

扩展使用本机 `offscreen` 文档完整校验原格式资源流、生成必要的预览副本，并持有下载用的临时 Blob。关闭面板或后台 Worker 重启会复用同一准备任务；任务结束后释放 Blob，不上传课件。当前行为见 [2.6.1 课程汇总与命名](docs/course-session.md)，早期格式验收见 [预览下载说明与验收](docs/preview-downloads.md)。

## 文件名、类型与内容校验

- 原文件名来自预览元数据；响应提供文件名时再次比对，支持 UTF-8、常见旧式 GBK 编码。名称冲突会停止该项，不会擅自替换后缀。
- 保留合法空格和原后缀。Windows 非法字符、保留设备名及超长名称会安全处理；深层保存路径有总长度上限，长名称带稳定标记，同名文件不会覆盖。
- ZIP 模式读取完整响应，检查实际字节数、PDF 结构、Office 内部文档类型和 ZIP 条目 CRC，原文件和平台整份 PDF 保持原始字节；明确标注的生成型预览副本除外。失败项可跳过，具体原因保留在面板。
- 普通原文件入口与直连预览文件在扩展原生下载前做最多 64 KiB 的预检；小文件可完成结构检查，大文件只读取文件头。服务器提供强 ETag 时会约束后续请求的版本。完成后核对 Chrome 提供的保存路径、名称及已知大小。
- 原站提供的空 ZIP 仍保留原字节，但显示“原 ZIP 为空”；加密文档或部分条目无法校验时也会提示，不把“传输完成”当作正文完整。
- 书签逐个下载直接保存已完整读取的小文件响应及本机生成的预览副本，避免再次请求；较大的普通直连文件仍交给浏览器下载。
- 预览页声明的原格式资源流必须完整读取和校验，扩展与书签都保存这一次读取的字节，不再发起第二次原生请求。已观察到 `resPdfShow.do` 将 PPTX/DOCX 标为 `application/pdf`；只对绑定当前资源的这条来源按实际 Office 结构校验，不放宽其他下载路径的 MIME 检查。逐个下载的该路径最多完整读取 200 MiB；ZIP 则遵守剩余打包预算。

**“浏览器已完成”不是逐字节内容认证。** 原生下载不会重新读取磁盘文件；PDF 结构检查也不等于验证每一页的语义。加密文档、ZIP64 和特殊压缩方式的检查有边界，详见 [下载验收记录](docs/download-integrity.md)。

## 项目结构

```text
src/runtime/       当前发布版的共用扫描、校验、网络读取、ZIP 和下载队列
extension/         扩展入口与标签页面板源码
web/               书签入口与官网源码
scripts/           发布构建和打包脚本
tests/release/     当前发布版回归测试
tests/browser/     真实 Chrome 验证
tests/fixtures/downloads/  可打开的合成文档样本（不含课程或账号数据）
src/platform/ 等  首版兼容实现，保留其测试和历史修复
public/、site/    首版模板与官网，不是当前发布入口
```

`npm test` 同时运行当前发布版与首版回归测试。`npm run test:browser` 使用本机 Chrome；非默认安装位置可通过 `CHROME_PATH` 指定。浏览器测试使用模拟课程与本机回环服务器，不使用真实账号；原生下载测试会核对实际保存文件的 SHA-256。

首版构建命令为 `npm run build:legacy` 和 `npm run build:legacy-site`，分别输出到 `dist/legacy-extension/` 和 `dist/legacy-site/`，不会覆盖当前发布版。
