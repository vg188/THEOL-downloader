# 课程资源助手

北京化工大学 THEOL 教学平台（course.buct.edu.cn）课件批量下载工具。非学校官方产品。

## 功能

- 一次汇总**课程资源**目录树与**单元学习**全部单元
- 树状勾选、类型筛选（PDF / PPT / Word / Excel 等）、搜索
- 优先打包 ZIP（可保留目录或文件平铺），超限自动改为批量下载
- 弹窗面板、下载设置（打包方式 / 目录结构 / 体积与数量上限）

## 仓库结构

```text
web/         书签版 + 官网源码（自包含书签、构建脚本）
extension/   Chrome 扩展（标签页面板，开发者模式加载）
```

## 书签版

1. 打开官网，把 **课程资源助手** 拖到书签栏
2. 登录 course.buct.edu.cn，进入「课程资源」或「单元学习」
3. 点击书签 → 弹窗汇总 → 勾选 → 下载

构建：`node web/build.mjs`

## Chrome 扩展

1. `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序
2. 选择 `extension/` 目录

## 隐私

不上传课件、文件名或账号信息；设置仅存本机。
