## 真实 Chrome 验证

当前发布版的浏览器用例实际执行了：

1. 加载构建后的扩展，并从嵌套 frame 读取列表。
2. 改变课程页内容后提交旧选择，确认没有发出文件下载请求。
3. 重新扫描目录树并核对文件数量。
4. 通过完整 `javascript:` 书签 URL 启动面板，而非只注入原始脚本。
5. 选择资源目录及单元文件，触发真实 Blob 下载事件，保存并解压模拟课程 ZIP。
6. 校验归档路径和每个条目的原始字节，检查桌面、480 px 扩展窗口和 390 px 书签窗口。
7. 通过本机回环服务器执行真实 Chrome 原生下载：13 个成功文件逐一核对原名、类型、保存路径和 SHA-256；5 个异常场景未误报成功。
8. 关闭面板并终止 Service Worker 后恢复下载，确认没有重复传输，真实并发不超过 2。
9. 书签 ZIP 保存 PPT／PDF／DOCX，逐个模式保存大 PPT 与小 DOCX；小文件复用同一份校验响应。
10. 使用独立文档库和本机 Microsoft Office 打开合成样本，核对正文、幻灯片和单元格。

其他浏览器用例保留了首版弹窗尺寸与单元学习回归。截图、模拟 ZIP 和逐项哈希证据位于 `output/playwright/release-flow/`、`output/playwright/download-integrity/`；这些是本地测试产物，不纳入版本库。

实际课程中检查了 17 个单元、4 个资源目录和 50 条资源；修复隐藏菜单混入、内嵌 PPT 漏扫及页面覆盖 `String.trim()` 的问题。50 条资源均未在当前页面提供原文件下载入口，面板将它们标为仅预览，不可勾选。初始仅预览课程的原文件下载请求仍为 0；本轮在另有明确下载入口的课程完成实际原文件验证。上一轮 2.5.3 重新加载初始课程后仍为 23 个课程资源、27 个单元资源、0 个选中，下载按钮禁用；本轮 2.5.4 在另一课程中扫描 76 条资源、选中 1 项，通过完整 UI 下载并核对 ZIP。详情见 [真实结构复核](live-structure-review.md)。
