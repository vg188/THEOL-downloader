# THEOL 单元学习双模式扫描设计

**日期：** 2026-09-12  
**状态：** 已批准  
**适用产品：** Chrome 完整版与自包含书签轻量版

## 1. 目标

在保留“课程资源/当前目录”扫描行为的同时，支持 THEOL“单元学习”栏目中的 PDF、PPT 和 PPTX。单元学习提供两个显式范围：

- **当前单元：** 默认，只扫描当前已经展开并加载的单元。
- **全部单元：** 用户主动选择后，读取当前课程的全部单元页面并汇总课件。

两个产品共享同一套纯解析和 URL 校验规则。功能不得下载课件正文来判断目录结构，不上传 URL、课程名、文件名、资源 ID、Cookie 或页面内容，也不得扩大到其他课程、站点、递归资源目录或自动翻页。

## 2. 已验证事实与待验证事实

真实 THEOL 页面已经验证：

- 自包含书签内联代码可以执行；
- 书签能访问当前同源 frame；
- Blob Worker 可以运行；
- “课程资源”的预览元数据请求成功；
- “单元学习”会在“第一次、第二次……”等单元中展示课件条目；
- GitHub Pages 远程脚本被页面策略或网络阻止，因此轻量版必须保持自包含，不依赖远程运行时代码。

仍需在实施前用只读结构探针确认：

- 单元入口的实际 URL 约束；
- 单元课件链接是现有 `download_preview.jsp`，还是另一种同源、可验证的预览路径；
- 未展开单元是否可通过同源 GET 得到与当前单元等价的静态页面；
- 页面声明的字符编码及单元标题位置。

探针只应输出布尔能力和非敏感的链接类型名称，不显示或上传实际 URL、查询参数、课程名、文件名、资源 ID 或响应正文。未确认路径时禁止猜测或拼装资源地址。

## 3. 用户行为

### 3.1 课程资源

课程资源页面继续只提供“当前目录”。扫描当前已加载目录，不递归子目录，不自动翻页。

### 3.2 单元学习

单元学习页面显示扫描范围控件：

```text
扫描范围：[当前单元 ▼]
          当前单元
          全部单元
```

“当前单元”直接解析当前已加载的单元内容，不请求其他单元页面。“全部单元”先显示将读取的单元数量和“不下载课件正文”的说明，用户确认后才开始遍历。

扫描初始不自动选择文件。切换课程、栏目、单元、扫描范围或页面文档代次后，旧选择失效。已提交的 Chrome 扩展后台下载任务不受影响；尚未提交的选择必须清空。

## 4. 方案决策

采用“当前 DOM + 经校验的同源页面读取”，不自动点击左侧单元。

| 方案 | 优点 | 风险 | 决策 |
| --- | --- | --- | --- |
| 自动点击每个单元 | 复用平台自身渲染 | 改变用户页面；依赖点击、动画和异步时序；容易扫错当前状态 | 拒绝 |
| 只解析当前 DOM | 请求最少、边界清楚 | 无法实现全部单元 | 仅用于当前单元 |
| 当前 DOM + 同源 GET | 不改变页面；可汇总全部单元；可独立校验每个响应 | 必须确认并严格约束单元入口路径 | 采用 |

“全部单元”是显式操作，不是打开面板、切换栏目或点击普通“扫描”后的隐式副作用。

## 5. 架构与模块边界

### 5.1 页面表面识别

扫描器先递归查看当前可访问的同源 frame，并把页面识别为以下表面之一：

- `resource-directory`：现有 `/meol/common/script/listview.jsp` 当前目录；
- `unit-study`：经真实探针确认的单元学习页面；
- `unsupported`：不满足严格规则的页面。

同一时刻必须唯一确定一个活动表面。若多个候选无法根据当前活动 frame 或课程 ID 唯一消歧，返回“页面有多个课件列表”，不得合并猜测。

### 5.2 解析器

保留 `parseDirectory(document, pageUrl)` 作为课程资源适配器。新增独立的单元学习适配器，接口按探针结果最终定名，但职责固定：

- `parseCurrentUnit(document, pageUrl)`：识别当前单元及其资源候选；
- `parseUnitIndex(document, pageUrl)`：枚举当前课程中的单元入口；
- `parseUnitPage(document, pageUrl, expectedCourse)`：验证单元响应并提取候选。

三个函数均为无网络、无 `chrome.*`、不修改 DOM 的纯解析函数。它们只返回规范化的上下文和预览候选；文件名、格式、大小、原文件下载链接仍由共享的预览元数据解析器确定。

### 5.3 扫描协调器

扫描请求携带：

```text
surface: resource-directory | unit-study
mode: current | all
courseId
unitIds / folderId
resourceIds
contextKey
```

- `resource-directory/current`：走现有单目录路径。
- `unit-study/current`：解析当前 DOM 后扫描候选元数据。
- `unit-study/all`：先获取单元索引，再以有限并发读取单元页面，最后扫描去重后的元数据候选。

单元页面读取与元数据读取使用独立并发上限。默认单元页面并发为 2，元数据沿用 3；每个请求沿用 15 秒超时、`credentials: 'include'` 和禁止不透明/跨站跳转的规则。中止扫描必须同时取消两级请求。

### 5.4 扩展与书签版

共享模块包含表面识别、单元解析、候选去重、URL 策略和错误分类。Chrome 扩展继续由后台桥保存扫描状态并校验消息来源；书签版由页面内协调器保存同页状态。扩展专属下载队列、`chrome.downloads` 和 `chrome.storage.session` 不进入共享模块。

自包含书签的构建产物必须包含全部运行时代码；不得恢复已被真实页面否决的 GitHub Pages 动态加载方案。

## 6. 数据流

### 6.1 当前单元

1. 用户位于单元学习页面并选择“当前单元”。
2. 扫描器唯一确定活动同源 frame。
3. `parseCurrentUnit` 验证课程与单元上下文并提取当前 DOM 中的预览候选。
4. 候选按首次出现顺序去重。
5. 共享元数据扫描器读取每个候选的预览页面，筛出 PDF、PPT、PPTX。
6. UI 展示结果、跳过数与失败原因。

此流程不得读取其他单元入口。

### 6.2 全部单元

1. 用户选择“全部单元”，确认将读取的单元数量。
2. `parseUnitIndex` 生成同课程的规范化单元入口列表。
3. 协调器以最多 2 个并发读取入口；每个响应重新校验最终 URL、登录状态、课程归属和页面类型。
4. `parseUnitPage` 提取资源候选，并为候选附加单元 ID、标题和顺序。
5. 按规范化资源 ID 去重；相同课件出现在多个单元时保留第一次出现的位置，同时记录其他来源供界面计数，不重复请求或下载。
6. 共享元数据扫描器处理汇总后的唯一候选。
7. UI 按单元顺序、单元内 DOM 顺序展示；单元失败不丢弃其他成功结果。

## 7. 上下文与失效规则

`contextKey` 必须覆盖影响结果的全部字段：表面、扫描模式、课程 ID、当前单元或有序单元集合、frame 文档代次和有序资源 ID。

以下任一变化都使未提交选择失效：

- 课程 ID 变化；
- 从课程资源切换到单元学习，或反向切换；
- 当前单元变化；
- “当前单元/全部单元”模式变化；
- 活动 frame 的 `documentId` 变化；
- 单元集合或资源集合变化。

完成扫描后、提交下载前必须重新检查上下文。检查期间若出现更新一代的扫描，旧检查不得覆盖新状态。

## 8. 安全与隐私

所有新路径必须延续现有策略：

- 精确接受 `https://course.buct.edu.cn`；拒绝 HTTP、其他主机、用户名密码、片段和重复关键参数；
- 只接受探针确认并写入允许列表的路径与参数组合；
- 数字标识使用现有长度和格式限制，不接受负数、指数、编码分隔符或多值参数；
- 单元入口必须属于当前课程；响应重定向、登录页、错误 HTML 或课程不匹配均失败；
- 不从标题、图标、DOM 顺序或相似 URL 推导下载地址；
- 只有预览元数据中存在且与资源身份完全匹配的下载入口才能进入下载流程；
- 页面文本只以 `textContent` 处理，面板不插入未转义 HTML；
- 不新增站点权限、Cookie 权限、遥测、远程日志或数据上传。

## 9. 错误与进度

全部单元扫描分为“读取单元”和“识别课件”两个阶段：

```text
正在读取单元 3 / 12，已发现 18 个候选
正在识别课件 7 / 18
找到 15 份课件；2 个单元、3 个资源未能识别
```

错误分为：

- 致命：不是支持页面、无法唯一确定活动列表、登录失效、单元索引无效、上下文变化；
- 局部：单个单元超时/结构未知、单个预览不可用、格式不支持、无原文件入口。

致命错误停止扫描且不提供陈旧结果。局部错误保留其他成功结果，并在折叠失败列表中按“单元读取失败”和“课件识别失败”分组。文件名等敏感页面内容不写入远程日志；本地界面可显示用户当前页面已经可见的标题。

## 10. 界面要求

- 课程资源页面不显示无效的“全部单元”选项。
- 单元学习默认“当前单元”，记忆仅限当前面板生命周期；重新打开或刷新后恢复安全默认值。
- 全部单元确认框显示单元数、额外页面请求说明和取消按钮。
- 扫描过程中禁用范围切换；取消后恢复控件。
- 搜索、格式筛选、选择保留规则沿用现有行为。
- 单元学习结果显示所属单元；重复课件只显示一项，可标注“另见 N 个单元”。
- 下载仍以课程名为文件夹；本阶段不新增单元子目录，避免改变现有下载路径合同。

## 11. 验证

### 11.1 自动化合同

使用完全合成的本地 HTML 夹具验证：

- 当前单元不请求、解析或返回其他单元；
- 全部单元按索引顺序读取并按 DOM 顺序汇总；
- 同一资源跨单元重复时只请求一次；
- 单个单元失败时保留其他结果并报告局部错误；
- 登录页、重定向、跨站、跨课程、伪造参数和未知路径被拒绝；
- 切换单元、模式、课程或文档代次使旧选择失效；
- 课程资源现有解析与下载合同不回归；
- 扩展和书签版对同一夹具产生相同候选集合；
- 自包含书签产物不含远程运行时加载器、遥测或数据收集端点。

### 11.2 真实页面门禁

分两次、由用户主动执行：

1. **只读结构探针：** 在一个当前单元和一个含多个单元的课程中确认入口路径、响应类型、元数据路径和字符编码；不请求课件正文。
2. **下载验收：** 实现完成后，由用户选择自己有权访问的一份小型课件，分别从当前单元和全部单元结果触发下载，核对文件名、格式、可打开性和重复项行为。

若结构探针发现单元学习没有稳定、可验证的同源入口，则“全部单元”暂停；不得退化为自动点击或猜测 URL。“当前单元”只有在当前 DOM 能提供经过现有安全策略验证的预览入口时才可交付。

## 12. 范围外

- 自动进入课程资源子目录；
- 自动翻页；
- 跨课程批量扫描；
- 扫描视频、作业、链接或非 PDF/PPT/PPTX 文件；
- 从课件正文推断格式或名称；
- 为兼容未知页面结构添加宽松 URL 通配规则；
- 恢复远程书签运行时代码；
- 改变 Chrome 扩展权限或绕过浏览器多文件下载策略。
