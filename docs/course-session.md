# 2.6.1 课程汇总与文件命名

日期：2026-10-09（Asia/Shanghai）。

## 同课内操作不要求重新汇总

- 扩展和书签首次汇总课程资源目录树，以及页面提供的全部学习单元入口；不再重复询问扫描范围。未发现单元入口时保留明确的空状态，不猜测不存在的文件地址。
- 汇总开始前复制课程页面结构和单元清单，异步读取过程中更改当前目录、单元菜单或 iframe 不会改变这次汇总的范围。
- 快照绑定学校站点和课程 ID，而不是当前 DOM、目录 URL、iframe URL、hash 或内容脚本实例。相同课程内切换目录、切换单元、打开预览、修改列表或重新打开扩展面板，都可继续使用原列表和选择。
- 扩展的“全部课程／课程资源／单元学习”是本地查看范围，不重新访问课程页面、不清空选择；后台缓存只保存一份目录树，避免重复存储正文和图片清单。
- 用户需要更新内容时主动点击“刷新列表”或“重新汇总”。真正换课、登录失效、离开学校站点或显式刷新替换了扫描 ID 时仍校验并拒绝不匹配的旧选择。消息只能提交已保存的文件 ID，不能传入任意下载 URL。
- 扩展已入队的任务不依赖面板；书签正在生成的 ZIP 仍依赖当前页面，不应刷新或关闭整个标签页。普通同课内点击不会让正在生成的 ZIP 作废。

## 文件名不添加来源后缀

预览入口是平台提供文件的一种方式，不是必须添加到文件名的版本标记。

| 平台内容 | 保存名称示例 |
| --- | --- |
| 预览页提供完整 PPTX | `第一讲.pptx`，保留原名与字节 |
| 原名与返回格式都是 PDF | `第一讲.PDF`，包括原扩展名大小写 |
| PPTX 的平台完整 PDF | `第一讲.pdf`，仅按实际格式替换扩展名 |
| 完整视频 | `课程视频.mp4` |
| 只有分页图片或富文本 | `第一讲.pdf` 或 `第一讲.html`，保留实际来源说明 |

不再自动添加“（预览版）”。教师原本就在文件名中使用的文字不会被擅自删除。平台原格式流、完整 PDF 和视频不因来自预览入口而被报告为非正式文件；只有本地合成或导出的内容保留必要的来源说明。文件内容、格式、大小、CRC 和权限校验继续执行，PDF 不会伪装成 PPTX。

- `npm test`：587 项通过，0 失败、跳过。
- 串行 Chrome 浏览器测试：9 项通过，0 失败、跳过。
- 新增 14 项课程会话回归：同课 DOM／目录／hash 变化、重建内容脚本、扫描中导航、换课、登录失效、列表缓存、显式刷新、焦点与刷新竞态、范围切换保留选择、下载中列表变化、清洁命名。
- 真实 Chrome 模拟课程：首次显示完整课程，切换 iframe 目录后原选择仍能入队；范围切换不改变扫描 ID；切换课程 ID 后拒绝旧选择；手动刷新才生成新的扫描 ID。
- 真实原生下载：清空课程页当前列表并改成另一个目录 URL 后，已选 PDF、PPTX、视频、图片合成 PDF 和 HTML 仍保存成功；逐个核对名称、内容与落盘大小。缺页、错误格式仍拒绝保存，关闭面板与 Worker 恢复仍通过。
- 原格式资源流保持原字节；整份 PDF 不请求分页图片；合成文件不输出缺页结果；文件名不出现工具生成的“预览版”后缀。

这些结果来自隔离 Chrome、合成样本和本机回环服务器，不替代所有真实课程、账号切换或学校登录状态的验收。2.6.0 的历史真实课件结果保留在 [预览下载验收](preview-downloads.md)。
