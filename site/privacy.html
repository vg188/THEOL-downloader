隐私政策

你的课件不会离开学校站点

本工具（书签轻量版与 Chrome 插件完整版）在你自己浏览器的当前页面里读取课件、打包并保存文件。不上传任何内容，没有遥测，没有统计、分析、广告或错误上报。

非官方说明：本项目是学生自制的独立工具，不是北京化工大学官方产品，与学校及课程平台运营方没有隶属或授权关系。

一句话摘要

你点击下载之前，工具什么都不会做；你点击下载之后，工具只向 course.buct.edu.cn 请求你选中的课件，并在本机把它们保存到下载目录。数据不会发往其他地方。

处理哪些数据，为了什么

数据类型、处理目的与去向
数据用途去向
当前课件目录的列表显示可下载的 PDF / PPT / PPTX 及其大小只在你打开的页面里，不离开本机
课件文件内容打包 ZIP 或逐个保存到下载目录直接从学校站点下载到你的浏览器
你已登录的会话以你的身份读取你有权访问的课件沿用浏览器已有的登录状态，不被读取或导出
文件名与大小显示清单、判断 500 MB 规则、生成 ZIP 内文件名只在本机内存中，不上传到任何服务器

我们不做的事

  • 不上传。课件、文件名、页面内容、下载地址都不会发往本项目或第三方的服务器；本项目没有后端，也没有中转或云存储。
  • 没有遥测。不含统计、分析、崩溃上报、错误 SDK、广告或任何“使用情况”上报。
  • 不读取密码、不导出 Cookie。工具不读取、不填充、不保存账号密码，也不会把登录 Cookie 复制到别处。
  • 不浏览其他内容。只处理你当前打开的那个课件目录里列出的文件，不会遍历其他课程、单元或个人页面。
  • 不绕过权限。工具不能下载你没有权限访问的课件，也不会尝试绕过平台限制。

网络请求

  • 本页只加载本站文件。页面样式与脚本都来自本站静态资源，没有第三方 CDN、字体、统计或图片请求。
  • 书签不加载远程代码。拖到书签栏的代码是自包含的，点击时不会从本网站或任何 CDN 拉取脚本。
  • 只请求学校站点。扫描与下载只访问 course.buct.edu.cn 上你当前目录里列出的课件资源，且只在你点击之后发生。

权限

  • 书签轻量版：不需要任何扩展权限，只在你点击书签时执行一次页面脚本。
  • Chrome 插件完整版：只申请 scripting、downloads、storage 与 course.buct.edu.cn 的站点访问权限，安装时由 Chrome 向你确认。
  • 本地下载：ZIP 与文件都保存在浏览器默认下载目录，不会同步到任何账号。

源码与联系

全部代码公开在 github.com/vg188/THEOL-downloader，你可以自行审计、构建或提出问题。请在 问题反馈 中报告隐私相关问题，不要附带课件内容、完整链接或账号信息。

本政策随功能变化更新，最新版本以本页与仓库提交记录为准。
