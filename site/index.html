书签轻量版需要桌面浏览器：手机和平板浏览器不支持把链接拖到书签栏，请改用完整版插件或桌面浏览器。

三步安装书签轻量版

  1. 显示书签栏。按 Ctrl + Shift + B（macOS 为 ⌥ + ⌘ + B）打开书签栏，把上面的按钮拖进书签栏。
  2. 登录并进入课件目录。在浏览器里登录 course.buct.edu.cn，打开要下载的课程，进入“单元学习”中的课件页面。
  3. 点击书签并确认。点击书签栏上的“THEOL 下载”，面板出现后点击“扫描当前目录”，勾选需要的文件，再在面板中确认下载。

如果拖拽不方便：点击“复制书签代码”，在书签管理器中新建书签，名称填“THEOL 下载”，网址粘贴刚复制的代码。

500 MB 规则、二次确认与保持页面打开

500 MB 以内：打包成一个 ZIP

所选文件的已知总大小不超过 500 MB（500 × 1024 × 1024 字节）时，工具会在页面内存中把它们打包成一个 ZIP 文件，然后一次性交给你。

超过 500 MB：改为逐个下载

已知总大小超过 500 MB 时不会打包，而是进入逐个下载模式。Chrome 可能弹出“是否允许此网站下载多个文件”的询问，选择允许后才会继续。

大小未知：同样按逐个下载处理

平台没有报告字节数的文件会被标记为大小未知。只要选择中存在大小未知的文件，工具就不会打包，而是在确认界面写明“另有 N 个文件大小未知”，并按逐个下载处理。

打包途中超过上限：销毁临时 ZIP

如果打包过程中实际读取的数据超过 500 MB，工具会销毁尚未发布的临时 ZIP 并回到确认步骤，不会自动改成逐个下载；是否需要逐个下载由你再次确认。

二次确认：先看清单，再触发下载

点击书签只是打开面板，此时不会下载任何东西。扫描之后还需要在面板中确认一次——这是第二步确认（二次确认），确认后才会真正触发下载或打包。

页面必须保持打开

书签在页面里直接读取你已登录的课件内容，因此任务期间请保持该页面打开，不要刷新或关闭页面，否则任务会中断，失败的文件不会由后台恢复。

“已触发”不等于“已完成”

完成后面板报告的是“已触发 N/M 个下载”——它只说明浏览器已经收到这几个下载请求，不代表文件已经保存完成。是否真正下载成功，请查看浏览器自己的下载列表（Ctrl + J）。

  • 不上传。课件文件、文件名、页面内容和下载地址都不会离开学校站点，本项目没有服务器、没有中转、没有云盘。

常见问题

点击书签后什么都没有发生

先确认当前页面是 course.buct.edu.cn 上的课件目录，而不是其他网站或本地文件。如果页面策略阻止了书签脚本，面板不会出现，此时请改用完整版 Chrome 插件。

在别的网站上点击了书签会怎样

面板会照常出现，但那个页面里没有课件目录可读，扫描会以空结果或失败结束。工具不会读取该网站的内容，也不会向它发起请求；请在 course.buct.edu.cn 的课件目录里使用。

面板里扫描不到文件

请确认已经登录且课程页面没有跳转到登录页；再展开含有课件的单元，确保课件列表已经加载出来，然后重新点击“扫描当前目录”。

浏览器拦截了多个文件的下载

逐个下载模式会连续触发多个下载请求。请在地址栏右侧的提示里选择允许“下载多个文件”，否则除第一个以外的文件都会被拦下。

为什么文件显示“大小未知”

平台没有给出这些文件的字节数。为避免超出内存限制，只要选择里存在大小未知的文件，工具就改为逐个下载，而不是打包 ZIP。

网页更新后书签会失效吗

不会。书签代码是自包含的，安装之后不依赖本网站，本页更新也不会让已保存的书签失效。想使用新版本，重新拖一次按钮即可。

想知道手上的书签是哪一版：在课件页按 F12 打开控制台，先点一次书签让面板出现，再执行 copy(__THEOL_DOWNLOADER_BOOKMARKLET_V1__.diagnose())，把结果粘贴到别处就能看到 stamp 字段，与本页“书签版本”旁的日期对照即可。这段诊断信息不含课程名、课件文件名和账号信息。

手机上能用吗

不能。手机和平板浏览器不支持把链接拖到书签栏，也无法在页面里加载书签脚本；请在桌面版 Chrome 或 Edge 上使用。

想用完整版插件，但现在商店还在审核

审核期间可以从源码仓库下载代码，用 Chrome 的“加载已解压的扩展程序”在开发者模式下本地加载。商店通过后，本页的按钮会变成“添加至 Chrome”。
