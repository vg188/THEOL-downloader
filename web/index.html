三步装好

  1. 显示书签栏：按 Ctrl+Shift+B
  2. 拖按钮进去：把上方蓝色按钮拖到书签栏
  3. 课程页点书签：登录 THEOL，打开某门课，点书签

拖到书签栏后点不开？Chrome 可能拦下 javascript: 书签。改用：右键按钮 →「复制链接地址」→ 书签管理器新建书签 → 网址粘贴。不要在本页点书签按钮（它只提示安装方式）。

标签版能力

弹窗面板

居中弹窗，可拖拽、可关闭，不霸占整个页面。

双板块标签

「课程资源 / 单元学习」两个总标签分开浏览，已选文件按板块分组。

独立汇总

不依赖你当前停在哪一页，主动拉取课程资源树和全部单元。

全部单元

自动探测单元列表并逐个读取，而不是只看当前单元。

类型筛选

PDF / PPT / Word / Excel / 压缩包 / 其他，一键过滤。

优先 ZIP

所选文件默认打包成一个压缩包；文件过多或体积超限时自动改批量逐个下载。

本地运行

书签自包含，不上传课件与账号，不加载远程脚本。

使用流程

  1. 登录 course.buct.edu.cn，打开一门课
  2. 点书签栏「北化课件 · 标签版」
  3. 弹窗自动汇总资源树与全部单元
  4. 筛选 / 勾选 →「下载所选」→ 核对浏览器下载列表

常见问题

为什么要进具体课程页？

书签只在你已登录的 THEOL 页面里读取当前课程可见资源，不能跨课、不能绕过权限。

汇总很慢？

「全部单元」会逐个读取单元页。单元很多时需要几秒到几十秒，进度会显示在状态栏。

Chrome 询问多个下载？

点「允许」。若拒绝，重新勾选后再下一次。

和插件版什么关系？

标签版书签适合马上用；插件版在开发中，会提供后台队列与下载记录。
