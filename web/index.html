三步使用

  1. 安装书签。把上面的按钮拖到书签栏。
  2. 打开课件页。登录 course.buct.edu.cn，进入某门课的「课程资源」目录或「单元学习」。
  3. 点书签 → 扫描 → 勾选 → 下载。面板会打开全屏标签界面，勾选后点「下载所选」。

常见问题

点了书签没反应？

确认当前页是 course.buct.edu.cn 的课程页，且书签代码完整（重新从本页拖一次）。

扫描到 0 个文件？

进入「课程资源」具体目录或「单元学习」，等列表加载后再点扫描。部分资源在 iframe 里，脚本会递归同源 frame。

Chrome 询问是否允许多个下载？

点「允许」。若拒绝，可重新勾选后再次下载。

后缀不对？

平台图标（powerpoint.gif 等）会推断后缀；预览页有真实文件名时会尽量补全。仍不对可手动改名。

和 Chrome 插件什么关系？

标签版书签适合快速体验、偶尔下载。插件版（开发中）提供后台队列与下载记录。当前请先用标签版书签。
